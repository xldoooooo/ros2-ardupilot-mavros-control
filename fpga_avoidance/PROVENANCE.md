# 成果归属与源码来源

第三方团队原创的范围仅为运行在 FPGA 上的 Ising/QUBO 优化器。本模块其余适配、轨迹生成及系统集成等工作均由项目作者完成，不能将整个 FPGA 避障工程归为第三方成果。
日常开发按具体模块和技术职责描述；仅在讨论优化器来源、板端接口或成果归属时说明上述边界，无需在任务中反复强调第三方。

`workspace/src` 取自项目作者提供的 `FPGA-avoidance-ros2` 工程。历史 ZIP 仅作为源码版本与问题复现基线，不代表包内全部代码的作者归属；其 SHA256 为：
`839ebd453906df8957b3f52e10dac319101c23ce537ecf0c6f6140c5c869a230`。
原包元数据声明 GPLv3，许可证见本目录 `LICENSE`。CPU 原生加速 ABI 3301，板端固件与 RTL 未改动。

本项目在 `FpgaKinoPathPlanner` 中维护 `plan_executable()` 和连续曲线验证，修正可执行轨迹与实际求解来源；
`flight_backend_node.py` 实现原飞行规划协议。源码完整保存在此独立工作区，构建和部署不依赖开发机上的外部副本。
旧演示、比较工具随原 Python 包保留；本集成的正式入口只有本目录的安装/构建/启停脚本。

历史包的固定哈希核验有三项不匹配；未改写其旧哈希或声称该历史核验通过。模块行为以当前源码与对应验证为准。
