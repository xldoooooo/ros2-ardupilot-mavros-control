# 上位机对接资料

- `无人机与上位机通信协议V2.2.pdf` 是当前协议原件；V2.0 DOCX 与 V2.1 PDF 保留用于历史对照。
- `websocket-server-1.0.0.jar` 为生产环境提供的主题路由服务器，只转发消息，用于本地模拟。
- `web_demo`、`web_demo_2`、`websocket_test_demo` 是历史联调示例，不代表当前地面站实现。
- 当前接入、消息格式与项目约定见 [WebSocket 对接](../../docs/websocket/上位机-WebSocket%20对接.md)；服务器启动见 [readme.txt](readme.txt)。
