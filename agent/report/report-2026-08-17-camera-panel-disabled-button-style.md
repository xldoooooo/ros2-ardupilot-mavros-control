# 摄像头面板启停按钮灰色禁用态修正报告

日期：2026-08-17

## 修正结果

摄像头面板的启停逻辑原本已经正确禁用按钮，但绿色 `success` 和红色 `danger` 角色
样式声明在通用 `QPushButton:disabled` 之后，覆盖了灰色禁用外观。因此按钮虽然无法点击，
视觉上仍像可用状态。

现已与地面站主 GUI 使用相同的角色按钮禁用规则：

- 文字：`#98a4b1`；
- 背景：`#edf0f2`；
- 边框：`#dbe0e5`；
- `primary`、`success`、`danger` 三种角色均显式支持灰色禁用态。

停止状态下，“开启摄像头”保持绿色可用，“关闭摄像头”显示为灰色禁用；运行状态下，
“开启摄像头”显示为灰色禁用，“关闭摄像头”保持红色可用。截图按钮等角色按钮也遵循
同一规则。
