# 任务 10-refine-2 追加修复简报

日期：2026-08-09

范围：处理任务基本完成后的 4 项 GUI 复核反馈

## 结论

4 项问题均已修复：起降与航点数值框恢复上下步进箭头并显示单位；策略选择改为一次完整显示三项的独立菜单；航点添加改为白色“+”；所有与飞行动作或航点编辑相关的数值输入会与对应按钮状态同步禁用和变灰。

本次仍只修改地面站 Qt 界面及测试，没有修改 ROS 协议、`ground_station_core/ros_controller.py`、`src/guided_interfaces/`、机载 C++ 或飞控参数。速度值仍是 UI 预设，不下传飞控。

## 修复明细

### 1. 步进箭头、单位与最小尺寸可读性

- 起飞高度显示 `m`，起飞/降落速度显示 `m/s`。
- 航点 X/Y/Z 显示 `m`，Yaw 显示 `°`。
- 上述 7 个输入框全部恢复上下步进箭头，同时继续忽略鼠标滚轮，避免页面滚动时误改数值。
- 为 1180×700 最小窗口单独压缩步进按钮宽度、输入内边距和字号。实测最窄状态仍完整显示 `-2.00m`、`90.0°`、`2.5m/s`，没有通过隐藏单位或降低数值精度规避问题。

### 2. 策略列表一次完整显示

旧实现仍调用 Qt 原生 `QComboBox` popup；真实桌面样式会在显示后重新限制列表高度，因此即使关闭滚动条也可能只露出部分条目。

现在 `DownwardComboBox` 使用专用 `QMenu`：

- 点击后固定移动到组合框正下方；
- 直接创建与模型等量的 3 个 action，不使用滚动视口；
- 弹层宽度至少容纳最长文本；
- 当前选项带勾选标记，选择后同步组合框索引及激活信号。

自动回归检查菜单 action 数量为 3、三项文字与组合框完全一致、最后一项几何位于菜单内部，且菜单顶部不高于组合框底部。

### 3. 白色“+”添加按钮

- “添加”改为“+”。
- 角色由蓝色 `primary` 改为普通 `neutral`，启用时为白色背景。
- 固定为 28×28 px，保留“将当前 X、Y、Z、Yaw 追加到航点列表”的 tooltip。
- 禁用时仍遵循全局灰色锁定样式，不会因白色专用样式覆盖禁用反馈。

### 4. 输入框同步状态门控

- 起飞高度与起飞速度仅在“起飞”按钮可操作时启用。
- 降落速度仅在“降落”按钮可操作时启用。
- X/Y/Z/Yaw 继续与航点编辑状态同步：无环境会话或航点执行期间统一禁用。
- 策略框、“+”及航点表格操作沿用同一航点编辑门控。
- 为 `QLineEdit`、`QComboBox`、`QDoubleSpinBox` 增加明确的禁用文字、背景、边框及步进按钮样式，使锁定状态与按钮一致可辨。
