# 右上角动态提示动画改进

本报告记录本次地面站视觉改动、实际验证及未覆盖边界。

## 实现

- 进行中：蓝色光带从左向右循环扫过，每轮 1.4 秒，连续进度消息不重置动画。
- 成功/结束：周边绿色光晕闪烁一次，1.2 秒后消退；新的成功事件可再次触发。
- 失败/异常：红色光晕以 1.2 秒周期持续闪烁，直到后续消息切换状态。
- 环境初始化、通讯检测、终止清理、命令等待与非 final 回执显式使用进行中状态。
- 保留源端日志等级；WARN 级导入/导出失败也显示红光，主动取消通讯检测结束显示单次绿光。
- 使用现有 PySide6 QVariantAnimation、自绘渐变与阴影效果，无新增依赖。
- 只修改地面站，不涉及机载部署、飞行控制或实机解锁/起飞。
