# 正式接入关键参数优先读取与 Odin 辅助节点耗时估算

本报告记录优先读取的生产实现、验证与部署，以及四个 Odin 辅助进程的粗略启动耗时；不裁剪插件或 Odin 节点。

## 实现与回退

onboard_control 经现有 MAVROS /uas1/mavlink_sink 路由按名称读取 GUID_OPTIONS、MOT_THST_HOVER，
使用 libmavconn 的标准 MAVLink 编码与 mavros_msgs 转换接口。不另开串口、不写参数、不发解锁/起飞。
新增显式 libmavconn 构建依赖，MAVROS 已依赖安装；部署检查与说明同步更新。

每次连接前 10 秒内最多四轮，间隔至少 1 秒；只请求未收到的参数。已武装、控制器启用或
状态超时不发送，断线重置重试状态和原事件缓存。只持有地面站租约不阻止只读请求，避免
SITL 地面站在初始化早期取得租约后失去优化。收齐仍通过原来的类型、bit 3、悬停推力范围校验；
不将请求成功或整表 ACK 当作 READY。原来的整表异步同步、缓存回退和定期复核均保留。

可通过 priority_parameter_reads=false 回退；parameter_request_topic、parameter_target_system、
parameter_target_component 可配置，默认 /uas1/mavlink_sink、1、1。消息源独立使用 255/190，
应避免其他发送端复用此标识。该路径不处理签名密钥：强制签名且拒绝无签名读取的链路应关闭
此优化，继续使用 MAVROS 原生同步，不降低链路签名设置。

## Odin 四个辅助节点：只估算，未修改

依据用户手动启动那一轮的 launch.log 和 odin.log，基准为每个进程的 process started 时间。
这是墙钟日志间隔与进程驻留数据，不是 CPU 独占时间，也不是逐个移除后的 READY 对照。

| 节点 | 观测间隔 | 解释 |
| --- | --- | --- |
| pcd2depth_ros2_node | 约 0.535 秒后正常退出 | senddepth=0，读取配置后不发布深度图 |
| cloud_reprojection_ros2_node | 约 0.562 秒后正常退出 | 配置关闭重投影，初始化后正常退出 |
| image_overlay_node | 约 0.342 秒完成初始化 | 持续运行；本轮约 815 秒累计 3 秒 CPU，约单核 0.37%，RSS 约 73 MiB；没有重投影输入，不能代表启用输入后的负载 |
| rviz2 | 约 1.21 秒建立 OpenGL，约 1.58 秒开始订阅点云；本轮生命周期 4.23 秒 | 本轮有显示环境并正常退出，不能把全生命周期算作初始化；无头 systemd 场景曾因无显示而退出 |

四个节点几乎同时 fork，开始时间相差不足 1 毫秒；与 Odin 主驱动及其他组件并行。
所以不能把 0.535+0.562+0.342+1.58 秒相加作为裁剪收益。前两个主要是短时无效初始化；
RViz 的图形初始化最值得从无头启动中移除，但本次没有 A/B，无法承诺具体 READY 节省值。
减少 Jetson 的辅助负载也不能直接等同于降低 Odin 本体温度。
