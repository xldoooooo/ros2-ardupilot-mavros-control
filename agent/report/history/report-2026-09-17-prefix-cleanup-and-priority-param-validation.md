# 清理重复 ROS 包查询与优先参数读取验证

本报告区分已部署的启动脚本修改与未接入生产的参数读取实验。插件裁剪仅形成独立方案，未实施。

## 已实施的最小改动

runtime_common.bash 新增 runtime_package_prefix，按当前 AMENT_PREFIX_PATH 的顺序读取
ament 包标记，替代每次启动 Python 的 ros2 pkg prefix；启动器打印路径也复用此函数。
不跨环境缓存结果，保留 source 后复核、缺包失败、重复 overlay/串口检查，以及离线启动、
GNU timeout 相对计时与原 READY 条件。生产改动只有两个 Bash 文件，无新依赖或构建步骤。

new 启动前 --check 单轮对照：旧版 6.223 秒，新版 1.727 秒，减少 4.496 秒。
不是多轮统计，也不是整套 READY 时间。完整启动的查询清理后对照轮 READY 为 28.867 秒；
之前参数事件版本的历史测量为 33.76/32.45 秒，跨轮差异不能全部归因于此修改。

24 项部署/启动相关测试通过，包括 overlay 优先级、环境切换、缺包、实际参数校验、断线、
校时与取消清理；bash -n 通过。未改动用户已有的 README/TODO/旧部署文档变更。

## 风险与备份

优先参数读取评估为中等工程风险，主要在消息编码/路由、重连状态、失败回退与重试边界。
只读 PARAM_REQUEST_READ 本身不写参数、不解锁；本轮不修改生产 C++、MAVROS 或飞控配置。
验证程序位于 agent/codex/startup-priority-20260917/priority_probe.py，不安装、不自启动。
使用 pymavlink 标准编码和 MAVROS 转换函数，经现有 /uas1/mavlink_sink 路由发送，
与 MAVROS 使用不同发送端标识，不另开串口。每个消息发布前解码核对目标 1/1、名称和索引 -1。
最多四轮、每轮仅两个名称；状态/心跳过期不发，检测到 armed/控制器活动/租约即退出。
生产化仍需处理路由与目标配置、MAVLink 签名、重连与缓存竞态，不应直接把脚本设为服务。

虽然未评估为高风险，部署 Bash 文件前仍备份 new 原件：
`/home/nvidia/ros2-ardupilot-mavros-control/agent/codex/startup-priority-20260917/predeploy.tar.gz`
SHA-256：5fa3f5f7b9ab612bc0950cf68970536289527074d4c42d41d4543d706c26d266。
该备份包含本轮两个被改动的启动文件，可在服务停止时恢复；无需回滚机载二进制。
已核对 new 与开发机两文件 SHA-256 一致。

## 参数读取实测

采用独立验证程序，不改变正常整表同步和必要参数值校验。
仿真收到两个参数事件约在请求后 56 毫秒；完整生产初始化成功，READY 44.495 秒，仍受
EKF/位姿冷启动限制。四个受管进程全部清理，无解锁/起飞。初次仿真探针状态话题名写错，
参数事件与原始回复记录有效；未武装/就绪取生产初始化记录，实机测试前已修正话题名。

new 第一轮仅清理查询、无优先请求：必要参数 28.424 秒，READY 28.867 秒，整表 36.805 秒。
new 第一轮优先读取：两个参数事件分别在请求后约 110/112 毫秒到达；必要参数 5.224 秒，
READY 7.497 秒，整表仍在 35.696 秒完成。只发送一轮两个请求，采集 401 条状态，
均未武装、无租约、控制器未启用。后续整表相同参数事件未撤销校验，未阻断后台下载。
以上启动时间均以该轮 systemd 单调 Started 日志为基准，不包含停止上轮服务的耗时。

new 短时复测：必要参数 4.398 秒，READY 7.643 秒，两参数响应约 109/110 毫秒；只发送一轮，
采集 131 条状态均未武装、无租约、控制器未启用。该轮约 16 秒后停止服务，不等待整表结束。

独立 DDS 无回复验证：最多 8 条读取请求后退出；模拟武装状态验证：0 条请求并退出。
该故障验证不连接飞控。首次故障验证 domain 233 超出
Fast DDS 端口范围而未运行，已改为隔离 domain 229 重测，不将第一次失败计为通过。
原生产回退路径也由不启用探针的实机对照轮验证；该实验不代表生产代码已具备优先读取能力。
