# Task 27 下视相机外参 180°修正简报

## 结论

当前生产 `T_imu_camera` 相对飞机上的实际相机安装方向，绕相机光轴反向约 180°。已将外参旋转
改为原始联合标定矩阵右乘 `Rz(180deg)`，平移保持原值，并同步到
`nvidia@192.168.112.169`。部署后的真机 `apply=false` 验证通过。

## 原因与修正

- 原矩阵把原始画面上方解释为 Odin IMU `+X`；受控摆放中 Tag 0 图案上方与机头同向，但算法
  稳定给出约 180°修正量。
- 相机采集与检测链没有软件旋转/翻转，AprilTag PnP 重投影残差正常，因此问题位于当前安装方向
  与生产外参之间，而不是 Tag 解码或画面显示。
- 修正采用 `R_new = R_raw * diag(-1,-1,1)`、`t_new = t_raw`，在完整 SE(3) 外参层处理，不在最终
  yaw 输出处打补丁。
- 配置测试新增安装方向约束：原始画面下方应接近 Odin `+X`，光轴应接近 Odin `-Z`。

## 验证结果

同一张 1920×1080 真机原始帧离线复算：

- 原外参：yaw `-179.926°`、tilt `4.580°`；
- 修正外参：yaw `-0.089°`、tilt `3.744°`；
- AprilTag 重投影 RMS：`0.704 px`。

飞机部署后再次运行 Tag 0 `apply=false`：

- 最终候选：`x=0.113407 m`、`y=-0.062821 m`、yaw `-1.369609°`；
- 314 个样本接受、1 个拒绝；yaw 标准差 `0.014569°`；
- 重投影 RMS `0.274783 px`，tilt `6.217317°`，处理约 `7.63 Hz`；
- 任务成功收敛后显式停止，相机设备已释放；
- extnav 始终 `correction_valid=false`、revision `0`，没有应用本次候选。

本地矩阵检查通过：`det(R)=1.000000000000001`，正交误差约 `1.6e-15`；相关配置测试直接调用
通过。项目 `.venv` 未安装 pytest 命令，因此未以 pytest runner 执行，但相同测试函数已使用项目
Python 环境逐项调用。

## 后续精度审计

针对台架发现的约 `5 cm` 平移差与约 `0.5°` 航向差，进一步审计得到：

- 任意完整 SE(3) 合成数据能恢复到机器精度，Tag 坐标转换、PnP 方向和
  `world_from_odin = world_from_tag * inverse(odin_from_tag)` 计算未发现代数错误；当前真机帧的
  PnP 次优分支重投影 RMS 为 `2.397 px`、tilt 为 `18.80°`，会被现有门限拒绝。
- 当前生产外参的水平杆臂为 `5.52 cm`。修正结果描述的是 Odin IMU 原点而不是相机光心；若物理上
  只把相机光心放在 Tag 中心，却拿 IMU 坐标和 Tag 原点比较，约 `5 cm` 偏移本身是预期几何量。
- 历史日志中，同一 Odin session 内不同任务候选的平移包络曾为 `4.86～7.14 cm`、yaw 包络曾为
  `0.24～1.44°`。每次任务内部标准差通常只有 `2～8 mm` 和 `0.015～0.05°`，说明当前质量门只
  证明约 2 秒窗口内稳定，不能证明跨位置、跨任务或绝对世界坐标准确。
- 生产外参基矩阵来自唯一接受的 `success01-run_20260827_233838`；该次标定开启了时间偏移估计，
  最终估计 `td≈162.6 ms`，且尚无使用硬件 PTS、固定 `td=0` 的多次独立从零标定来验证其绝对
  精度。另一个未验收、不能直接用于生产的候选矩阵与其相差 `4.66 cm/0.465°`，暴露了外参可观性
  和重复性风险，数值量级与台架现象一致。
- 当前真机候选 residual tilt 为 `6.22°`；在约 `0.669 m` 观测距离上，数度姿态系统误差足以产生
  厘米级平移敏感性。现有 `8°` tilt 上限过宽，不能作为 `5 cm` 绝对精度的验收门限。
- 1920×1080 内参 RMS 为 `1.449 px`，在本次距离下通常只对应毫米级局部位置灵敏度；除非运行时
  分辨率、裁剪、变焦或实体 Tag 尺寸不一致，否则它不是本次 `5 cm` 差异的首要嫌疑。

因此，180°方向修正仍成立，但当前证据不支持把剩余误差归为不可避免的随机噪声，也不支持宣称
已达到厘米级/亚度级绝对精度。首要风险是参考点理解、Tag 的实测位置/朝向、外参标定重复性和
Odin 移动后的漂移；程序还缺少跨位置闭环与多轮重复性验收。精度问题未在本次配置修正中解决。

## 安全与剩余边界

全过程飞机保持 `connected=true`、`armed=false`、`STABILIZE`、`ON_GROUND`；没有发送解锁、
起飞、模式、姿态、速度、位置或航点命令。

本次只确认并修正了 180°安装方向错误。剩余约 1.37°包含 Tag/机体摆放、Odin 本次建系和原始
标定误差；Tag 的绝对位置与朝向、外参跨轮重复性均未做测量级验收，因此本结果不能替代飞行前的
世界坐标精度、EKF 创新与长时间稳定性验证。
