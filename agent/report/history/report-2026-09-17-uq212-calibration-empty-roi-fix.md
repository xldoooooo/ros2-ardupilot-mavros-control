# UQ212 标定空 ROI 崩溃修复

日期：2026-09-17。

## 问题与证据

用户移动相机时 sample_quality 的 cv2.Laplacian(board_roi) 因 !_src.empty() 退出。
旧实现直接用 boundingRect 返回值做 NumPy 切片。通过 x=-0.5 的边缘角点构造，
boundingRect 的 x=-1 导致从图像末尾切片，稳定复现空区域；这是与用户堆栈一致的原因。
现场失败帧未保存，不能声称已取回并复现那一帧的准确角点。

## 修改

- 在 ROI 计算前拒绝不足4点、非有限值和越界角点；ROI 边界仍裁剪且检查非空。
- 在透视变换前检查单应矩阵，拒绝无效矩阵/非有限投影；只在几何评估处处理预期异常，
  未通过捕获主循环所有异常来隐藏问题。
- 当前几何无效时清空当帧可采纳数据并重置连续稳定计数，不清空已采纳样本。
- 空格强制采样共用已验证 descriptor，不再次绕过几何检查计算无效区域。
- 不改清晰度、最少Tag数、样本数或畸变模型，不删除已有数据，不覆盖旧相机结果。
