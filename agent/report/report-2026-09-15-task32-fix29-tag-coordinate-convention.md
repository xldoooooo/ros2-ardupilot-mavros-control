## 2. 逐项回答任务问题

### 2.1 Task29 的数学方法是否成立

成立，但前提是所有变换的坐标定义正确，Odin 与世界水平面能够由同一个刚体 SE(2) 对齐。
记 `H_AB` 把 B 系坐标变到 A 系：

```text
H_OT = H_OI · H_IC · H_CT
H_WI = H_WT · inverse(H_CT) · inverse(H_IC)
C_full = H_WI · inverse(H_OI) = H_WT · inverse(H_OT)
```

首次从 `C_full` 直接提取 x/y 平移和 yaw。之后每个已知 Tag 中心提供一对
`P_i = center_W(Tag_i)`、`Q_i = translation(H_OTi).xy`，求：

```text
min Σ w_i || P_i − (R(ψ)Q_i + t) ||²,  w_i = 1/σ_i²
ψ = atan2(Σw_i(qx·py − qy·px), Σw_i(qx·px + qy·py))
t = P̄ − R(ψ)Q̄
```

其中 p/q 是减去加权质心后的坐标。当前实现符号、权重、平移求解正确，旋转行列式为正，
没有镜像或尺度自由度；每轮使用原始 P/Q 重算，没有把历史修正重复累加。两个不同且分离的
点即可观测二维旋转；两点残差不能充分识别离群点，真实可靠性仍需要多点与独立检查点。

局限也必须保留：Odin 漂移、Tag 测量误差、安装误差、非共同水平面和时间匹配误差会破坏该
模型。丢弃 `C_full` 的 roll/pitch 后，结果不再与完整 SE(3) 对任意三维点完全等价；误差含
`[(Rz(ψ)−R_full)p_O].xy`。在约0.7～0.8m高度变化下，2°的小角度误差通常就有约2～3cm
的位置敏感性。不能据此改写成错误的平移补丁，也不能宣称绝对精度已验收。

### 2.3 Task29 的 Odin→FCU 杆臂 T 修正是否正确

对于当前已核实零安装角，`T=(+0.06,−0.03,+0.05)m` 表示 **FCU 指向 Odin IMU 的机体系
向量**。若 Odin 世界位置为 p、姿态为 R，则：

```text
p_FCU = p_IMU − R·T
```

所以有效世界修正后的水平公式 `(Qp+t−QRT).xy` 正确。旧实现额外的固定 `+T_xy` 只会带来
`(+0.06,−0.03)m`，长度约6.71cm，不会反转相机位置，也不足以解释20多厘米的当前偏差。
无效分支的 `p+T−RT` 是原有局部零点约定；Task29 保留它以保持未标定时的既有行为。
本次没有改 extnav、T 数值、z 约定或飞行控制节点。

### 2.4 为什么 yaw 合理，位置却反向

OpenCV 的标准 PnP 点序是0/1/2/3；现场官方纸张物理角点对应关系是：

| 官方纸张角点 | 左上 TL | 右上 TR | 右下 BR | 左下 BL |
|---|---|---|---|---|
| OpenCV 点号 | 2 | 3 | 0 | 1 |

项目约定 `+X官方上 / +Y官方左 / +Z朝上`，因此：

```text
旧 R_OpenCVTag_ConfiguredTag = [[0,−1,0],[ 1,0,0],[0,0,1]]  ← 错180°
新 R_OpenCVTag_ConfiguredTag = [[0, 1,0],[−1,0,0],[0,0,1]]
```

Tag0 在原点，错误 Tag 方向会将由图像反算的相机世界位置 x/y 同时反号。相机外参中另加
180°可以让机体 yaw 看似恢复正常，却不会恢复相机的真实世界位置。首次把这个错误平移冻结
到 Odin 世界修正后，后续搬动的增量仍按几乎正确的 yaw 前进，错误的原点偏移持续存在。
这就解释了“向 Tag 中心移动，读数反而更正、更远”的观感。

同一历史帧、同一 PnP、不改内参和杆臂的四种对照：

| 变体 | FCU 完整几何 x/y（m） | yaw（°） |
|---|---|---:|
| 两处旧错误同时存在 | +0.0194 / +0.0679 | −23.156 |
| 只修 Tag | −0.0194 / −0.0679 | +156.844 |
| 只恢复相机外参 | +0.2180 / −0.0204 | +156.979 |
| 两处同时修复 | −0.2180 / +0.0204 | −23.021 |

这里是同一原始帧的离线几何结果，**不是实际搬动飞机后的新测量**。截图中原始、corrected、
FCU、MAVROS 各级读数本身也符合旧公式，证明不能仅靠各级数值一致来排除上游坐标错误。
上述对照对应约 `(+0.2374,+0.0475)m` 的原点偏差；若忽略移动中的漂移与倾斜耦合，移回中心
后这项偏差仍会保留。任务截图还包含约−0.8m的raw高度变化，残余tilt可额外产生厘米级误差。
由于截图所对应任务没有保存完整同步输入，不能把这张历史对照帧当作截图的精确数值重建。

### 2.5 是否相机倒装或 Tag 上下标记反了

保存的现场图里能看到纸上手写“上”，对应的位图与官方 PNG 一致。独立下载官方 Tag0、1、2，
在本机 OpenCV 4.6 中均得到 BR/BL/TL/TR 点序；飞机 OpenCV 4.14 的原生检测和方向回归也
得到相同约定。当前采集驱动没有 flip/rotation/crop 操作。

因此，原先“看到约180°的 yaw 差就确认相机倒装”的证据不成立；本次应该修复 Tag 基变换，
撤销那次外参补偿。恢复原标定后，当前帧的残余倾斜约1.7°，与用户描述的拆装后小角度误差
量级相符，但不能取代重新外参标定。
