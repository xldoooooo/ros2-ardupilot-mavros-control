# 航点列表即时编辑

日期：2026-11-02

## 结果

- 航点列表 X、Y、Z、Yaw 可双击直接编辑，也支持选中单元格后键盘输入。有效数值输入即时写入本地列表，无需回车、失焦或额外确认。
- 编辑复用现有 `waypoints_changed` 通知，已打开的 RViz 预览自动更新航点、朝向与连线，无需重新点击预览。
- 编号保持只读；数值范围、小数位数与顶部输入一致，Yaw 显示角度、内部存储弧度。未实际修改的采点/导入值保留原始精度。
- 复用原有导入、导出、排序、删除、发送及执行期间编辑锁定逻辑。编辑只修改本地待上传列表，不自动上传或改变机载任务。

## 实现

生产改动仅位于 `ground_station_core/qt_ui/waypoint_panel.py`：使用 Qt 数值编辑委托，在输入变化时修改对应航点的单个分量并发出原有通知。避免每次按键重建表格，保持编辑焦点、输入文本和光标；Qt 结束编辑的同值信号不截断原始精度。

`tests/waypoints/test_waypoints_gui.py` 增加一个真实键盘交互用例，覆盖中间航点四项即时更新、预览复用、角度换算、其他点精度保留、排序和执行锁定。
