# 航点单元格编辑尺寸修复

日期：2026-11-02

## 结果与实现

双击编辑时，数值编辑器和内部文本框均贴合原单元格，不再增大或覆盖相邻行。即时更新、本地列表、预览与原有数值约束保持不变。

原因是共享输入框主题包含 `min-height: 30px`、内边距和焦点边框，实际编辑器高度为36px，而航点单元格为27px。仅在 `ground_station_core/qt_ui/waypoint_panel.py` 的单元格编辑器上清除这些样式并隐藏步进按钮，不修改全局主题。

## 验证

- 本机 offscreen Qt 实测：修复前单元格与编辑器分别为136×27、136×36；修复后编辑器及内部文本框均为136×27，坐标与原单元格一致。面板截图已目视核对。
- 在现有四列即时编辑用例中增加尺寸相等断言；键入即时更新、预览和原始精度断言继续通过。
- `bash tests/run.sh --group waypoints -- -q`：67项 Python 测试及3个现有 C++ 测试套件通过，没有失败或跳过。C++ 使用既有构建产物，本次未改动其源码。
- 本次文件 `git diff --check` 通过。
