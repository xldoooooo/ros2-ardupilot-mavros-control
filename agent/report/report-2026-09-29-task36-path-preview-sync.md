# Task36 路径预览闪断与输入匹配修复

## 原因与修改

- 修复前15秒采样124次成功、4次盲区时间匹配失败；同时间戳对应4条空Path，造成RViz清屏。
- 独立库d2e3a69：单帧异步缓存等待后到的里程计，默认最长0.15秒，须小于等于输入超时。
  源时钟匹配容差仍0.05秒；新到点云不能续期旧等待，成功处理仍使用原接收时间。
- 等待期间旧地图遵守原新鲜度约束；超过期限清图并报告STALE_INPUT，不隐瞒失败。
- `/kino_path`只发送成功非空预览，失败不再发布空Path。`/plan_result`每次照常报告，
  失败segments/trajectory仍为空；预览是历史显示而非当前可执行结果，文档已明确。
