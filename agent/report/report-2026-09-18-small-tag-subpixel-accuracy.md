# 小尺寸 Tag 亚像素角点精度复核

## 问题与结论

用户反馈候选外框筛选修复后单Tag校准出现约5cm水平偏差，确认size_m测量编码最外黑边。
此测量方式正确，现场Tag0/1均为0.099m。本次不调整该尺寸、Tag坐标、相机内外参、
首次完整SE(3)投影公式、滑窗或extnav杆臂，也不以常量平移补偿掩盖误差。

发现并修复另一项角点问题：原固定7px半径对应15×15精修窗口；现场缩放后的编码边长
约57px，每格仅约7px，窗口容易跨到相邻编码结构或外框。当前实拍63帧的原精修角点
全部停留在整数像素，位姿解算明显不稳定。此前“稳定识别”和轴对齐角点测试不足以
验证小尺寸旋转Tag的公制精度，不能作为5cm绝对精度保证。

OpenCV4.6 cornerSubPix源码确认：精修点偏移超过窗口半径时会退回初始点：
https://github.com/opencv/opencv/blob/4.6.0/modules/imgproc/src/cornersubpix.cpp
源码与同图观测一致，但没有逐迭代追踪每个角点的内部失败分支。

## 最小实现与验证

检测器先解码未精修轮廓，再对每个已配置Tag按最短边长选择精修半径：
`max(1,min(7,floor(shortest_edge/16)))`。36h11为8格，半径最多半格。
保留40次迭代、0.01精度、原内参缩放、畸变、IPPE_SQUARE和全部质量门。

新增独立投影真值：9.9cm Tag、82cm深度、四个平面转角、有/无外围框，共8场景。
同时约束内部角点<0.8px和水平位置误差<12mm。旧代码4个带外框场景全部失败，
新代码8项全部通过；不是放宽原方向测试或只验证ID。

- 本地correction测试：101 passed。
- refresh隔离overlay原生新/旧外框回归合计：15 passed。
- 修复overlay实机重新开流：62/62识别，单/双Tag配置ID一致。
- Ruff和diff检查通过。没有完整真实校准重应用或绝对精度验收。
