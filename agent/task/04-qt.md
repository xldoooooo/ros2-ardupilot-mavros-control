# QT GUI

## 任务描述

使用Pyslide, 将本项目tkinter实现的地面站GUI替换成Qt实现，并完全移除tkinter。本任务核心聚焦于GUI重构，不要修改飞行控制算法等无关内容。



## 要求与注意事项

1. 整体风格为：浅色主题 简明硬朗 大方美观 的工程软件风格。重要内容可以适当突出强调，但不要花里胡哨五颜六色
2. 界面布局/层级/交互逻辑进行合理重构，不需要保持与原GUI一致。重构前后各个原功能保持对应即可。
3. 在某一状态下，互斥/禁止操作的按钮等组件，应当被禁用。例如，在未启动任何仿真或实机连接时，应当禁用所有飞行控制等无效按钮；
4. 在进行高危操作时，应当弹出警告提示框供用户二次确认
5. 主界面底部或右侧，应当有一个显示实时日志的框，集中统一显示所有日志消息；按照重要程度划分为debug/info/warn/error，且能够根据日志等级筛选显示。（日志等级应当在日志产生时同步生成，而不是地面站自己判断属于什么等级）
6. 如果地面站有必要获取某些信息，可在机载服务增加相关通讯。
7. 界面应当能够适配不同分辨率的显示，随拖动正常放大/缩小
8. 合理安排项目文件架构，具备可维护性与可读性，不要全部gui代码都杂糅到一个文件中；保留单文件主界面入口，方便启动
9. 检查项目记忆，历史任务及执行报告，结合项目代码，将此前存在的与GUI相关的尚未修复的问题或bug一并修复解决
10. GUi界面组件的种类，布局和大小要合理，不能拥挤/重叠/错位，也不要过于稀疏/丑陋。
11. 本次任务较复杂，你要反复仔细认真调试，自行运行并观察GUI界面，测试各组件功能是否正常等。然后生成详细任务报告。
