# 对接工作调研

本次为调研任务，不执行具体代码修改。



## 任务背景

当前地面站在整个工程中的地位如下：

我们的无人机 <-> 我们的地面站ground_station.py <-> 甲方的上位机上的地面站 <- 甲方操作人员

也就是说，我们的地面站要负责与甲方自己开发的地面站进行对接，将甲方地面站发送来的指令进行解析处理，发送给无人机；同时将我们无人机发来的数据进行解析转发等

integration文件夹内的docx文件是甲方发来的文档。



## 任务需求

你现在调研，当前地面站项目要想集成这个与甲方地面站通讯的功能，最好的修改方式 设计模式是什么，要如何实现，难度如何，给出详细分析。例如，是将对接功能单独集成到一个子模块实现，还是将功能嵌入GUI主界面，还是其他方法。

还需留意的是，甲方的需求里有一些可能可以复用我们已有的逻辑，比如发送无人机自身状态的日志什么的。然后可以对日志发送/处理方式进行适当改进，让两个地面站同时使用1条日志，这样避免无人机发送过多消息

本项目目前还不能实现甲方的某些需求（例如 一键返航），具体无人机如何实现，算法怎么写，你不需要关注，你本次重点关注项目架构。这些以后加入的功能只需要预留接口即可。

注意，甲方可能后续的需求会发生变化，所以我们的代码不能全写死，要预留一定的可改造空间。

注意，甲方说 上位机和无人机之间采用**原生****websocket****协议** **+** 。。  这个先不要管。我们上位机暂时就用ros2在局域网通讯的方案即可
