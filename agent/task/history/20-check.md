# 悬停漂移BUG排查



真机现在悬停的时候（不论用我们的PD+DOB, 还是AP原生PID），间隔一段时间会出现一次明显的漂移后回正，幅度在10cm以上。这个大幅晃动有时悬停10就会出现，有时悬停30秒就会出现，有时可能30秒也不出现。而且在地面站仿真中是不会出现的。排查真机代码，确认以下事情：

1. 旧odin.sh相关逻辑是否被本项目新加的机载服务或其他修改给破坏或变动
2. 地面站相关逻辑是否影响到mavros或相关的程序；机载服务或地面站是否影响到了飞控
3. 现在怀疑可能是odin硬件问题，也可能供电问题导致的，但没有明确证据，你能否进行一定程度的检查。因为我们希望在改动硬件之前，先要分析排除是否为软件bug所导致。
