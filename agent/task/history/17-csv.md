# 从CSV导入航点

增加一个功能，可以从csv文件批量导入航点



## 任务需求

现在航点任务只能手动点击添加，我希望可以从csv文件导入



1. csv文件格式：

   + 第一行：表头，从左向右：第一列：index, 第二列 x 第三列 y 第四列 z 第五列 yaw
   + 从第二行开始，每行代表1个航点
   + 位置单位为米，偏航单位为角度

2. 导入时，从第1个航点依次导入；合理选择一个数字，作为单次导入的最大允许个数，用于安全限幅

3. 导入后，会清空GUI列表已添加的所有航点（添加二次提示框）

4. 航点坐标是绝对坐标，就跟手动添加的航点的逻辑一致。

5.

   ![image-20260812104540109](/home/nvidia/scq/projects/ros2-ardupilot-sitl-hardware/agent/task/assets/image-20260812104540109.png)

在这一行的最右侧，添加一个按钮“从文件导入”，普通白色，点击后 打开资源管理器选择文件。（只支持单个文件）

6. 支持直接拖动文件到列表内 也会触发导入功能（二次提示框）
7. 写一个示例csv文件方便我待会手动测试
