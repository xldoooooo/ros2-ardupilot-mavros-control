# 手动操作模式UI界面修改

修改调整GUI界面，要求如下：



1. 将当前左边两部分进行重新排列。现在的排列方式是左右排列：左栏 上方是环境与连接，下方是飞行动作；中间栏是手动运动意图。你修改成上下排列：上方第一排：左边是：环境与连接；右边是：飞行动作； 下方第二排：是手动运动意图。
2. 手动运动意图内部进行修改：改成飞行手柄（美国手）的排列：左边四个键一组，对应关系是：WS-上升下降 AD-左转右转；右边四个键一组，分别是：IK-前进后退 JL左移右移。 空格悬停单独放在居中下方。
3. 把现在的灰色解释文字”W/S上下 I/K 前后 J/L 左右 A/D 偏航。。。“ 这行删除
4. 实际位姿等信息在运动意图栏里的左下区域。
5. 把”手动运动意图“文字 修改成 ”手动操纵 “



本次针对GUI界面修改。如无必要，请勿修改控制逻辑等无关代码
