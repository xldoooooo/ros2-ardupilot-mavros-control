# 界面美化与修复

当前QT基本功能已实现。经过我的实际使用与观察，你需要做出如下调整或修复



1. 有两处显示颜色问题：如图所示：

   ![image-20260806225859486](/home/nvidia/scq/projects/ros2-ardupilot-sitl-hardware/agent/task/assets/image-20260806225859486.png)![image-20260806225923953](/home/nvidia/scq/projects/ros2-ardupilot-sitl-hardware/agent/task/assets/image-20260806225923953.png)

   这七个文本框右侧的上下按钮方块，内部是纯白色，可能你的箭头并没有正确渲染出来。

   修复之

2. 当前，鼠标悬停在上面这七个框框的时候，若滚动鼠标滚轮，则会自动改变这些数值。我不想要这样，把这个功能禁用。

3. 把最头顶的![image-20260806230104910](/home/nvidia/scq/projects/ros2-ardupilot-sitl-hardware/agent/task/assets/image-20260806230104910.png)

   这个 去掉。他占用了上面很多空间，白白浪费了界面。改进一下布局，使得这几个字的右边那一块地方不要被白白浪费.

   同理，![image-20260806230644039](/home/nvidia/scq/projects/ros2-ardupilot-sitl-hardware/agent/task/assets/image-20260806230644039.png)

   这五个状态展示组件也是，占用过多空间。改进一下。注意是改进一下，不要全删掉导致GUI界面缺少必要信息。

4. 下方日志的按等级筛选功能，现在是只能选中一种等级，显示选中的这一种。我现在希望改成：可以勾选每个等级，以独立决定是否显示它。例如可以勾选debug和error,则会过滤并显示这两个等级的日志。

5. 现在，连接与飞行动作 和 手动控制与遥测，是共享左半栏，通过鼠标点击上方标题切换。我要求你改成：这两个界面将同时直接显示在主界面中，连接与飞行动作面板 在最左边，手动控制与遥控，在中间，航点任务在右边。这样从走向右依次三栏。注意修改大小以适配。

6. 在无人机飞行过程中，先添加航点，然后发送并执行航点，在执行完毕后，我点击清空航点，发现“执行与进度”这个进度条不会清空。这个可能是BUG,检查并修复。

7. 为这个gui界面左上角添加一点菜单栏，例如“帮助”，“设置“ 等，并添加一些实用功能；添加一个“终端”按钮，效果是点击之后在当前目录下启动一个terminal

8. 为窗口添加四周边缘与阴影。
