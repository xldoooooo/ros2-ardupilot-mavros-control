# 通讯协议测试

根据目录下integration目录内的东西，在本地完成websocket双端通讯模拟测试



当前架构是：

对方1个地面站 -> 对方自行维护多个websocket -> 多个我方地面站 -> 我方每地面站只控制1架飞机

这一步我们正在模拟测试的是：对方的地面站 - websocket - 我方地面站 这一步的通讯。我方为client



## 要求

1. 本次只在单独integration目录下完成，不集成到现有地面站中，禁止修改integration文件夹外的内容，实现的独立websocket client 通讯 demo

2. 权威参考是甲方发来的那个jar文件，和通讯协议V2.0.docx

3. 这个通讯协议并不完备，但你不需要自行完善它，只需要按照现有要求 实现其全部功能即可。比如它缺少ack协议，则你不需要自行补充。

   甲方的要求就是：假设网络是在局域网内，网络连接始终处于100%理想状态，不会丢包也不会有大延迟，默认甲方地面站按下某个按钮，其消息一定能够传到我方地面站

4. 使用python实现，完成全部协议内容测试。

5. 提供我能直观验收的结果展示与复现命令入口

6. 可能有另外的进程正在处理本项目的其他部分，你不需要理会，只在此子目录实现一个独立模块即可

子目录下AGENTS有一些说明

子目录下readme里，是甲方技术人员发给我的，简单介绍了使用方法，你可以参考。里面有关截图，应该是Postman的测试界面。

缺少的环境你自己往本机安装即可。（本机有一个IDEA和JDK,但不一定适配版本，你自己检查确认）
