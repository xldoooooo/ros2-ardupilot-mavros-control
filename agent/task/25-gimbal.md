# 云台控制集成

将云台控制写成一个独立的模块，可以实现从地面站发送指令/设置 的方式进行控制。



实现的独立性等规范可以参考video_service模块的代码以及任务/任务报告

其他具体要求如下：



## 地面站云台控制面板

在地面站主GUI的右上角，“摄像头配置面板“的左侧， ”上位机通讯面板“的右侧，添加一个：”云台控制面板“按钮，点击后打开一个面板。上面的内容是



+ 三轴角度的设置输入栏，（俯仰，滚转，偏航），单位为角度
+ 每个输入栏后面，有单独的选项，可以选择是 “锁定”模式（比如设置俯仰0 锁定模式，则无论飞机怎么动，摄像头的俯仰都应该相对地球坐标系水平） ，还是 “跟踪” 模式（跟随底座，比如设置0偏航跟踪模式，当他向右看的时候，不论飞机怎么旋转，摄像头都还应该向（飞机的）右侧看
+ 提供一个“应用修改”按钮。所有设定 修改后不会即时生效，只有点击这个按钮的时候，才会向云台发送指令并使其修改状态。



### 其他

把XFAY demo 里面的你认为有用的功能/信息，在这个面板上进行实现/展示



+ 有一个必须要实现的：

  对比显示当前云台实际三轴角度（从云台读取到的）与给他下达的指令角度。

  这个实际三轴角度以10Hz进行更新。
