# 按问题选择证据

文件链接相对本文件。入口提供当前字段与实现，事故分析仍需核对事发版本；这里不保存主机地址、参数值或未关闭事故的固定答案。

## 定位、外参与 Tag

入口：[导航坐标](../../../../docs/odom-map.md)、[Tag 工作流](../../../../docs/tag-waypoint-workflow.md)、[修正服务](../../../../correction_service/README.md)。

- 优先配对原始 Odin、extnav、飞控 BIN 和任务状态的重叠时段。飞控收到外部位置不证明已融合；创新量是观测与预测之差，超限本身不能证明哪一侧错误。
- 明确日志对应的 EKF 实例/lane、实际主输出及切换时间；字段含义以对应飞控版本为准，不能拼接不同实例形成轨迹。
- 观测融合恢复不证明上游在该时刻才恢复；需要同时比较观测、预测/融合值、创新/方差与接受状态。没有独立真实轨迹时，不把单一路径或短窗惯性积分当绝对真值。
- 比较位置/姿态前核对 ENU/NED、FLU/FRD、角度单位、时间和传感器/FCU参考点。安装变换、世界修正、原点偏移的责任按当前实现追踪，不凭话题名推断坐标。
- Tag 候选求解、事务 ACK、active revision 和飞控融合接受分别取证；采集停止或清窗不能单独证明修正失效。拟合残差、重复性及绝对精度分开表述。

## 遥测、DDS 与控制停顿

入口：[机载诊断说明](../../../../src/onboard_control/deploy/ONBOARD_DEPLOYMENT.md)、[启动与日志](../../../../docs/startup-and-logs.md)；字段实现位于 `src/onboard_control/` 和其 `deploy/mavros_diagnostics/`，相对仓库根目录。

- 按需比较设备输出、MAVLink 帧解析、MAVROS 处理/发布、DDS 源与接收、控制回调/缓存及控制输出；未被采集的环节标未知，不把最上游可见日志当物理源。
- `link_receive` 位于帧解析后，不能证明此前串口字节连续；`gap_ms` 可能包含前次调用耗时，不能直接等同断流。慢调用事件、未返回调用和回调年龄有不同含义。
- 样本时间前进但接收延后，与源样本本身停顿需要不同解释；恢复后收到旧样本不等于源端恢复新鲜数据。对比进程 CPU、线程调度和锁/发布耗时，只对有观测覆盖的层级归因。
- 某事件（如开相机）先发生只是关联；若对照未复现或其他条件也触发，不能固定该事件为原因。降低消息频率或延长超时可能改变症状，不能据此证明根因已修复。

## 规划与闭环运动

入口：[避障桥](../../../../src/avoidance_bridge/README.md)、[FPGA](../../../../fpga_avoidance/README.md)。

- 区分输入地图/点云、原生规划、桥接后参考、控制实际消费参考及实飞轨迹；冻结同一输入、初态、目标和参数后才能比较算法结果。
- 区分段内、段间、跨计划的 p/v/a 连续性与解析一致性；平滑图形不等于动力学可执行。
- 说明净空相对于体素质心、原始点、障碍表面还是机体边界；规划净空不能替代跟踪净空。
- 回读实际采用的 CPU/FPGA/MOCK/回退来源；板卡响应或代码包含 FPGA 调用不证明最终使用了 FPGA 路线。

## 命令、媒体与跨端状态

入口：[上位机协议](../../../../docs/websocket/上位机-WebSocket%20对接.md)、[视频服务](../../../../video_service/README.md)。

- 按 source、命令 UUID、任务序号、航点和媒体会话关联事件，核对每个字段作用域，避免同序号跨设备/重启串轮。
- 分清接收、入队、socket 发送、ACK、业务终态及物理状态。发送返回成功的含义从实际实现确认；无业务 ACK 时不能宣称恰好一次交付。
- 沿采集→推流→地面处理→文件入库→读取→业务回报检查故障段。文件存在不证明完整可解码，播放成功不证明覆盖整段巡检；迟到媒体与冻结的业务终态分别取证。

这些入口用于定位问题。若任务是新增状态机功能、修改外参或部署设备，按对应开发/部署要求工作，不因涉及上述模块就强制执行事故复盘。
